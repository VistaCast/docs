# 目标场景

VistaCast 用同一套视觉平台服务多类现场。场景是**配置与模型组合**，不是多个互不相通的产品。

## 商业零售

**适合**：奶茶 / 快餐 / 连锁门店。

**能力**：客流计数与时段对比、高峰提醒、区域关注；告警可推送到业务群或 Webhook。

**价值**：用已有枪机看清进店节奏，辅助排班与运营，不必先换硬件。

## 仓储物流

**适合**：仓库、卸货区、夜间无人值守区域。

**能力**：夜间活动提示、周界 / 入侵、摄像头离线提醒。

**价值**：异常更早被看到，并可联动通知与远程查看。

## 产线光学

**适合**：中小制造、插件 / 组装 / 标签 / 胶路等工位。

**能力**：缺件、错件、偏移、条码；焊点类（虚焊 / 连锡 / 冷焊等）按工位演进；普通工控机 / 桌面 CPU 即可作为识别主机。

详见 [产线光学检测](/guide/pcb-aoi)。

## 工业安全

**适合**：工厂危险区、通道、禁入区域。

**能力**：危险区有人、跌倒 / 烟雾等异常类型可配置；与告警分级、出站联动。

## 居家看护

**适合**：家属看护、居家运营商、摄像头品牌合作。

**能力**：跌倒与夜间异常候选、联系人级联通知、同意与确认流程。

**产品原则**：不自动拨打急救电话，不做健康诊断；通知到人，由人决定下一步。

详见 [家庭看护](/guide/guardian)。

## 园区周界

**适合**：园区、场地出入口与周界枪机。

**能力**：复用入侵与离线能力，按站点配置规则与值班通知。
