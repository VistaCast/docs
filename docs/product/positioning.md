# 定位与愿景

**Slogan**：Scene intelligence · Line optics（场景智能 · 产线光学）

## 一句话

**行业视觉平台** — 兼容已有 ONVIF / RTSP 摄像头。商业零售、仓储物流、产线光学是主场景；工业安全、居家看护、园区周界在同一引擎上扩展。不做远程桌面，不做默认全量云录像。

## 两条产品线

| 产品线 | 服务对象 | 交付方式 |
|--------|----------|----------|
| **行业场景** | 连锁、仓储、工厂、集成商 | 按场景开通与部署 |
| **家庭看护 / OEM** | 家属、居家运营商、摄像头品牌 | 同一引擎上的看护与白牌合作 |

## 愿景

让每一路摄像头成为可编程的视觉传感器，持续产出安全、运营与看护事件，并接入分析、物联与远程介入闭环。

## 产品边界

| 范围内 | 范围外 |
|--------|--------|
| ONVIF / RTSP 接入与管理 | 远程桌面（→ [VistaRemote](/ecosystem/vistaremote)） |
| 边缘 AI 检测与规则告警 | 默认全量录像长期托管 |
| 客流 / 安防 / 产线光学事件 | 通用 BI（→ [DataLuminary](/ecosystem/dataluminary)） |
| 按需 WebRTC 预览 | 无人审核自动拨打急救电话 |
| OEM 与看护扩展 | 与厂商封闭云互相锁定 |

## 差异化

| 维度 | VistaCast |
|------|-----------|
| 接入 | 兼容存量 ONVIF / RTSP |
| 数据 | 事件优先，不是换一台 NVR |
| 预览 | 按需预览，优先端到端 |
| 部署 | 可私有化，Docker 自建 |
| 扩展 | 场景插件 + LuminaryWorks 生态 |

## 典型客户

- 连锁零售运营
- 仓储与园区值守
- 中小制造 / 产线光学
- 工厂危险区管理
- 系统集成商
- 摄像头 OEM 与家庭看护运营商
