# 架构概览

VistaCast 采用「核心引擎 + 场景插件」：

```text
摄像头 / 推流  →  进流与检测  →  规则与告警  →  管理台 / 客户端 / 出站
                      ↑
                 边缘或同区域 AI（不在浏览器内嵌模型）
```

- **控制面**：账号、设备、规则、告警、预览信令
- **检测面**：拉流或接推流、推理、上报结构化事件
- **观看面**：浏览器、桌面、手机按需 WebRTC 预览

更细的模块边界见产品仓库架构说明；对外能力见 [能力总览](/product/capabilities)。
