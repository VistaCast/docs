# LuminaryWorks 生态

VistaCast 是 [启明工坊 LuminaryWorks](https://luminaryworks.dev) 六产品中的 **「视」**——负责空间感知与视觉事件。

## 价值链

```text
编排 BlockyEdu → 采集 SyncroBrain → 分析 DataLuminary → 感知 VistaCast → 介入 VistaRemote → 价值 DoerFlow
```

## 兄弟产品

| 产品 | 与 VistaCast 的关系 |
|------|---------------------|
| [DataLuminary](https://dataluminary.dev) | 接收结构化事件，做看板与分析 |
| [SyncroBrain](https://syncrobrain.com) | 告警联动现场设备与工单 |
| [VistaRemote](https://remote.vistacast.dev) | 告警后远程人工确认与接管 |
| [DoerFlow](https://doerflow.dev) | 将视觉事件纳入价值与任务网络 |
| [BlockyEdu](https://blockyedu.com) | 培训与编排场景 |

VistaCast **可独立部署商用**，也可以按需接入兄弟产品形成闭环。

## 统一身份

生态产品共享 [LuminaryWorks 身份](https://luminaryworks.dev) 登录能力；无统一 IdP 时亦可使用本地账号。
