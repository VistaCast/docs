# VistaRemote

[VistaRemote](https://remote.vistacast.dev) 负责**远程人工介入**（桌面 / 移动设备控制），与 VistaCast 的「自动感知」互补。

| | VistaCast | VistaRemote |
|--|-----------|-------------|
| 载体 | 固定枪机 / ONVIF / RTSP | 电脑、手机、机器人等 |
| 价值 | AI 感知、事件、告警 | 远程确认、双向控制、审计 |
| 协作 | 发现异常并发出信号 | 接收信号并接管现场 |

典型路径：VistaCast 夜间仓库告警 → 通知值班 → 一键打开 VistaRemote 与现场通话或操控。
