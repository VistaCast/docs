# 产线光学检测

产线光学（AOI）是 VistaCast 上的**工厂场景**，与门店客流、仓储值守共用同一平台，不是另一个独立产品。

## 适合什么现场

- 节拍不是极快流水线、标准整线 AOI 覆盖不足的中小代工
- 异形插件、抽检要求高的汽车电子、柔性板（FPC）等工位
- 希望用普通工控机 / 桌面电脑做识别主机，而不是一上来就上云 GPU

## 能力规划

| 类型 | 说明 |
|------|------|
| 缺件 / 错件 / 偏移 | 工位 ROI + 经典视觉或检测模型 |
| 条码 / 标签 | 有无、歪斜等在位类判断 |
| 焊点 | 虚焊、连锡、冷焊等按工位模型与阈值配置 |
| 胶路 / 组装 | 断胶、螺钉 / 接插件在位等相邻工位 |

检测在边缘或工位主机运行；管理台配置工位、阈值与告警，不在浏览器里加载模型。

## 怎么接入

1. 选定工位摄像头与固定机位（光照尽量稳定）。
2. 按 [三种部署方式](/guide/deployment-modes) 部署门店 / 产线盒子或直连服务器。
3. 在管理台绑定摄像头，配置 ROI 与场景包。
4. 告警走与门店相同的规则与出站通道。

评测与样张流程见 [工厂场景评测](/guide/eval)。

## 与零售 / 仓储的关系

同一租户可同时开零售客流与产线光学：共享账号、摄像头资产、告警与权限模型，按站点切换场景配置即可。
