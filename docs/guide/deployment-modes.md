# 三种部署方式

把枪机或 VistaCast 定制摄像头接到平台，让总部、店长用**电脑或手机**按需看门店画面。

VistaCast 做的是 **AI 视觉与事件**，不是远程操作电脑（那是 [VistaRemote](/ecosystem/vistaremote)），也不是厂商封闭云录像。

---

## 怎么选

| 现场情况 | 推荐方式 | 说明 |
| :--- | :--- | :--- |
| 店里有一台能跑 Docker 的迷你主机 / 工控机 | **A · 门店盒子** | 本店拉流与检测，远程按需预览 |
| 装不了客户端，只有传统枪机 | **B · 直连服务器** | 摄像头推流到已部署的进流网关 |
| 希望拆盒即连、用户自配 Wi‑Fi / 服务器 | **C · 定制摄像头** | 出厂激活后自动入网，机身网页改网络 |

```text
路径 A  枪机 ──RTSP──► 门店盒子 ──事件 / 信令──► 控制面
                      ▲
         远程 Electron / 浏览器 / 手机预览（优先 P2P，必要时 TURN）

路径 B  枪机 ──RTMP / WHIP / 国标──► 进流网关 + 同区域检测
                      ▲
         远程观看同一套预览；店里可以没有 VistaCast 客户端

路径 C  定制机出厂激活 → 默认走 B（也可改回店内局域网 RTSP）
         用户用机身网页改网络 / 服务器
```

---

## A. 门店盒子

适合连锁安装：**一台盒子管本店摄像头**，总部或店长远程看。

1. 现场准备可跑 Docker 的主机，按 [门店盒子与家庭壳](/guide/store-box) 安装。
2. 枪机电源与网线接入店内网络。选购建议见 [买摄像头并接入](/guide/add-camera)。
3. 在管理台 **设备接入**：填写局域网 RTSP → 测试拉流 → 保存并绑定摄像头。
4. 控制面可与检测同机，也可把检测留在店里、API 指向总部（见 [设备接入向导](/guide/device-setup)）。
5. **远程观看**：用管理台、桌面端或手机 App **按需预览**。无人观看时不必长期往公网推视频流；请勿把 RTSP 裸暴露到公网。

跨网预览依赖 [ICE / TURN](/guide/ice-turn)。

---

## B. 枪机直连服务器

店里装不了 Docker 时：让**摄像头自己推流**到已运行的 VistaCast 进流网关。

适合说明书支持 **RTMP 发布** 或 **GB/T 28181** 的工程机。不建议只支持厂商 App 云回看的消费款。

1. 在公网可达（或 VPN）的机器上部署 VistaCast，启用进流网关与检测服务。
2. 在摄像头后台配置：
   - **RTMP**：`rtmp://服务器地址:1935/<应用名>/<流名>`
   - **GB28181**：按网关下发的 SIP 域 / 编号 / 密码填写
3. 本机确认网关再发布地址可播后，在管理台登记为 RTSP（填再发布地址）。
4. 绑定完成后检测上线；远程预览同路径 A。

分步说明：[设备接入向导](/guide/device-setup) · [多协议进流](/guide/camera-ingest) · [验收与联调](/guide/delivery-test)。

---

## C. 定制摄像头

目标体验：拆盒上电 → 自动连接服务器 → 用户用机身网页改 Wi‑Fi 或更换服务器。

| 能力 | 说明 |
| :--- | :--- |
| 设备激活 | 一次 token / claim，设备注册到租户 |
| 配网页与出厂配置 | 网络、服务器地址可改；量产 BOM 按合作推进 |
| 模组开发指南 | 见 [定制摄像头](/guide/camera-module) |

尚未拿到定制机时，用路径 A / B + 普通工程机即可。协议样机可参考 [ESP32 参考套件](/guide/esp32-kits)。

## 远程看画面

| 端 | 入口 |
| :--- | :--- |
| 浏览器 | 管理台 → 摄像头 → 预览 |
| 桌面端 | 首页「看门店画面」 |
| 手机 | 首页「看门店画面」（连接可达的管理台地址） |

新枪机接入仍走 [买摄像头并接入](/guide/add-camera)。手机底栏「检测」是手机自带摄像头，不是门店枪机。

---

## 持续检测与云端监控

- **门店盒子通电运行**时，本店可按配置持续做检测与告警（需现场保障供电与网络）。
- **托管进流 / 云桥**、以及 **定制摄像头托管服务**，用于希望由平台侧保障可用性的场景，见 [混合推理与云桥](/guide/hybrid-infer) 与商务开通流程。
