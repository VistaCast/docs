# 混合推理与云桥

VistaCast 默认在**边缘或工位主机**做检测；需要时再编排云端视觉服务做回退、抽检或核验。管理台与官网不加载模型权重，也不自建云 GPU 集群作为主路径。

## 三层能力

| 层 | 作用 |
|----|------|
| 边缘本地 | 门店盒子 / 工位电脑持续拉流检测，时延低、数据可不出场 |
| 端侧窗口 | 桌面或手机在预览窗口内做补充识别（见 [窗口内识别与对话](/guide/client-infer)） |
| 云桥 | 按量调用第三方云视觉，用于抽检、疑难帧或无边缘算力时的补充 |

## 云桥适合什么时候用

- 现场暂时没有合适的边缘主机
- 需要第二路核验，降低漏检争议
- 特定模型只在云端提供

开通与计量见 [计费说明](/guide/billing) · [开通与授权](/guide/commerce-ops)。

## 与部署方式的关系

- 路径 A（门店盒子）：本地检测为主，云桥可选
- 路径 B（直连服务器）：检测跑在服务器同区域
- 路径 C（定制机）：出厂入网后同样可走本地或云桥策略

详见 [三种部署方式](/guide/deployment-modes)。
