# 光照与相机选型

这一页给出分辨率、快门、接口、光源、遮光和识别主机的选型参数。

数字是设计起点。视野、工作距离和最小特征以 [勘察清单](/guide/site-survey-checklist) 为准。机位代号 S1 / S2 / W1 / W2 / W3 见 [SMT 与波峰焊取像](/guide/smt-wave-imaging)。

环境光会盖过焊点、现场又不能遮光时，先改工位，再开始两周采集。

## 分辨率怎么定

```text
µm/px = 视野宽度 ÷ 相机像素宽度
```

视野用毫米时：毫米数 ÷ 像素宽度 × 1000 = µm/px。视野宽度按实际拍到的实物宽度量，不按传感器宽度。

最小要看的特征至少占 **5 个像素**。这条用来选相机和视野，不是焊点合格线。

![100 mm 视野除以 5000 像素约等于每像素 20 微米](/guide/resolution.svg)

演算：视野 100 mm，像素宽度 5000，则 100 ÷ 5000 = 0.02 mm/px ≈ **20 µm/px**。5 个像素对应 0.1 mm。0.3 mm 的间隙是 15 个像素，满足 5 像素。若最小特征只有 0.08 mm，则 0.08 ÷ 0.02 = 4 个像素，不够，就要缩小视野或增加像素。

像素落在大约 5–12 MP 这一档，是因为工位视野常常需要这个量级。公式先算，再看结果落在不落在这一档。一台相机不够就分区，每区一台固定相机。

## 相机与镜头

| 参数 | 选型 |
|------|------|
| 快门 | 全局快门。在线板子在动，卷帘快门会把焊点拍斜。离线治具上板子是停的，工位相机仍统一用全局快门 |
| 分辨率 | 约 5–12 MP，由上一节的公式决定具体一档 |
| 镜头接口 | C 口，固定焦距 |
| 数据接口 | USB3 或 GigE。相机就在主机旁边用 USB3；距离远用 GigE |
| 不采用 | 手机、消费级自动对焦摄像头、变焦镜头当工位镜头 |

焦距用规格书上的传感器宽度估算，再试拍确认边缘：

```text
焦距 ≈ 传感器宽度 × 工作距离 ÷ 视野宽度
```

三项用同一长度单位。演算例子：传感器宽度 8.8 mm，工作距离 300 mm，视野 100 mm，则焦距 ≈ 8.8 × 300 ÷ 100 = 26.4 mm，取接近的固定焦距。这是算术例子，不是采购清单。治具先把工作距离固定，再定焦距。

## 光照与遮光

![低角环形光、同轴或穹顶、彩色分层](/guide/lighting.svg)

| 参数 | 选型 |
|------|------|
| 起步 | 低角环形光，突出焊点外形和连锡 |
| 反光压不住 | 加同轴或穹顶 |
| 要看焊角倾斜 | 彩色分层环形光：不同角度不同颜色，一次曝光，用颜色通道做特征 |
| 遮光 | 遮光罩。天窗和工位灯不能直接打在焊点上 |
| 在线 | 频闪，与曝光同步 |
| 离线、板子静止 | 可以用常亮，仍然遮光，避免亮度随天窗变化 |

频闪的脉宽按位移来定，不预设一个固定微秒数：曝光期间板子的位移要小于一个像素。位移 ≈ 线速度 × 曝光时间，像素尺寸用上一节的 µm/px。试拍确认没有拖影。

彩色分层里的颜色表示照射方向，用来提取焊角。它不提供芯片底部或内部的信息。

## 触发时的频闪

| 现场 | 拍摄 |
|------|------|
| S1、W1，板子停在治具上 | 扫码或脚踏后拍；常亮或频闪都可以，必须遮光 |
| S2、W2、W3，板上有运动 | 到位信号触发，曝光窗口内频闪 |
| 没有光电、PLC、扫码枪或脚踏 | 画面稳定后拍，写进勘察单 |

到位信号只用来拍照。不改链速，不写设备参数。

## 识别主机

| 可以用 | 说明 |
|--------|------|
| Apple Silicon | 桌面机，例如 Mac mini 这一类 |
| Intel 或 AMD 台式机 | 普通工控机或台式机 |

**Intel Mac（M1 之前的 x86 Mac）始终不是识别主机。**

起步工位把主机选在上面两类里。独显不是起步配置。工位不依赖云端 GPU。模型在工位主机上运行，管理台不加载模型。

证据磁盘的空间和告警见 [证据保留策略](/guide/quality-evidence-retention)。数据默认留在这台主机或客户厂内的磁盘上。
