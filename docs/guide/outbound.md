# 告警与出站

告警在规则命中后生成，可在管理台确认、标误报或关闭，并推送到外部系统。

## 出站方式

| 方式 | 用途 |
|------|------|
| Webhook | 推送到自有服务；可做签名校验 |
| 邮件 | 值班邮箱 |
| 企微 / 钉钉 | 业务群机器人 |
| MQTT | 对接现场或中间件（可与 SyncroBrain 等联动） |

## 典型流程

1. 配置检测与规则（时段、区域、类型）。
2. 配置出站端点与最低告警级别。
3. 用测试投递确认对端可达。
4. 生产告警进入历史列表，可导出。

生态联动示例见 [SyncroBrain](/ecosystem/syncrobrain) · [DoerFlow](/ecosystem/doerflow)。
