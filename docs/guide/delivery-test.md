# 验收与联调

把摄像头接到 VistaCast 后，用本清单确认「能拉流、能告警、能预览」。

## 准备

- 已按 [快速开始](/guide/quick-start) 或 [Docker 部署](/guide/docker) 起好环境
- 至少一路可达的 ONVIF / RTSP（或 RTMP / 国标推流）
- 管理台账号可登录

## 检查项

| 步骤 | 期望结果 |
|------|----------|
| 1. 登录管理台 | 进入仪表盘 |
| 2. 添加摄像头 | 保存成功，列表可见 |
| 3. 测试拉流 | 检测侧显示在线 |
| 4. 配置一条简单规则 | 规则保存成功 |
| 5. 触发或模拟事件 | 告警列表出现记录 |
| 6. Webhook / 通知（如已配） | 对端收到告警 |
| 7. 按需预览 | 浏览器或客户端能看到画面 |
| 8. 跨网预览（如需要） | 打不通直连时经 TURN 可看 |

选购与接线见 [买摄像头并接入](/guide/add-camera)；部署形态见 [三种部署方式](/guide/deployment-modes)。

## 产线光学

若开通产线场景：确认 ROI、工位配置与告警类型符合现场；详见 [产线光学检测](/guide/pcb-aoi) · [工厂场景评测](/guide/eval)。

## 看护场景
