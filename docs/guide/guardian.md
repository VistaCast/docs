# 家庭看护

家庭看护把「跌倒、夜间异常」等事件，通过**联系人级联**送到家人或值班人员，并与 OEM 摄像头激活共用同一套 VistaCast 引擎。

## 产品原则

- **通知到人**：系统给出候选与提醒，由人确认后再升级通知
- **不自动拨打急救电话**
- **不做健康诊断或医疗结论**
- 需完成同意与合规配置后，相关能力才可启用

## 规划能力

| 能力 | 说明 |
|------|------|
| 家庭空间 | 独立于门店站点的家庭 / 看护空间 |
| 联系人级联 | 按顺序通知；超时未确认可升至下一人 |
| 确认窗口 | 可配置等待确认时间 |
| 同意管理 | 未同意则相关能力不可用 |
| OEM 激活 | 定制机出厂后一次激活加入租户 |
| 与行业场景共存 | 同一平台，权限与空间隔离 |

## 适用对象

- 家属与居家运营商
- 希望做看护增值的摄像头品牌（见 [OEM 伙伴](/guide/oem-partner)）
