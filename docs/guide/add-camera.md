# 买摄像头并接入

## 选购建议

优先选择说明书明确支持 **ONVIF** 或 **RTSP** 的工程机 / 枪机。若店内无法部署盒子，选择支持 **RTMP** 或 **GB/T 28181** 推流的型号。

尽量避免：只能厂商 App 云回看、无标准协议的消费套装。

## 接线

1. 电源与网线接入店内网络
2. 在摄像头网页查看 RTSP 地址或开启 ONVIF
3. 在 VistaCast 管理台添加设备并测试拉流
4. 绑定后配置规则与预览

完整路径见 [三种部署方式](/guide/deployment-modes) · [设备接入向导](/guide/device-setup)。
