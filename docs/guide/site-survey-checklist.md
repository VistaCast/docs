# 现场勘察清单

PoC 采集之前填写。单上的尺寸、节拍和遮光条件，用来修订取像方案里的设计起点。填完的单子是 [质检 PoC](/guide/poc-playbook) 勘察阶段的产出。

光照盖不住焊点、又不能加遮光罩时，先改现场，不约采集周。

## 怎么用这份清单

现场工程师填写，品质或工艺在「结论」栏确认。每一行的「记录」留空给现场，不预填别的工厂的数字。

方案代号的含义见 [SMT 与波峰焊取像](/guide/smt-wave-imaging)。相机和光源参数见 [光照与相机选型](/guide/lighting-camera-selection)。

## 基本信息

| 项 | 记录 |
|----|------|
| 客户 / 工厂 / 产线 | |
| 日期、填写人、客户对接人 | |
| 工位类型：回流后 / 波峰后 / 包装 | |
| 板型名称或料号 | |
| 现有目检岗位（人数、班次） | |

## 板子

| 要量的内容 | 记录 |
|------------|------|
| 板子长 × 宽（mm） | |
| 最小焊点间隙或最小要看的特征（mm） | 用来核对是不是至少 5 个像素 |
| 单面还是双面 | |
| 载具类型 | |
| 焊接面是否被载具、链条或托盘挡住 | |
| 有没有对位用的 Mark 点 | |
| 能否导出贴片坐标（位号、X、Y、旋转、封装） | 回流后工位用来生成焊点区域 |

## 节拍

| 要问的内容 | 记录 |
|------------|------|
| 每块板允许的检测时间（秒） | |
| 日产量（块） | |
| 班次 | |
| 离线放治具是否容得下这个节拍 | |
| 在线是否允许到位后停住再拍 | |

## 现有信号

| 要问的内容 | 记录 |
|------------|------|
| 光电：有无；到位时能否发出 HTTP 或 MQTT | |
| PLC：有无；到位时能否给出信号 | |
| 条码枪或脚踏：有无 | |
| 板上条码的位置、一维 / 二维 / Data Matrix、会不会被助焊剂挡住 | |
| 没有上述信号时，是否接受画面稳定后拍摄 | |

触发方式的对应关系见取像指南。没有信号也可以采集，在结论里写明用稳定画面触发。

## 环境

| 要看的内容 | 记录 |
|------------|------|
| 工位空间：相机工作距离能不能留出 | |
| 环境光：天窗、工位灯，会不会盖过焊点 | |
| 能否安装遮光罩 | |
| 振动来源（相邻设备、输送） | |
| 温度、助焊剂挥发（波峰出口） | |
| 相机若放在板子下方：防污和防热怎么做 | |
| 识别主机放在哪里；磁盘剩余空间 | |
| 数据是否留在厂内（默认留在厂内） | |

## 验收标准

| 要问的内容 | 记录 |
|------------|------|
| 内控文件名称，或 IPC-A-610 等级 | |
| 连锡、漏焊、锡珠、透锡各自按哪一条 | |
| 通过品抽检比例（复判人力要用） | |
| 不能接受的漏检类型 | |
| 哪些位号必须走 X-ray、ICT 或功能测试 | |

透锡是否合格，以这里记下的客户规范或 IPC-A-610 等级为准。清单不写死填充百分比。

## 现有检测设备

| 要问的内容 | 记录 |
|------------|------|
| 现场有没有 AOI 或其他自动检测 | |
| 客户现有设备覆盖哪些工位 | 只记录现场事实 |
| 哪些工位仍然靠目检 | 这是 PoC 的候选工位 |

这里只记录客户已经在用的设备，用来看缺口。

## 样本与数据

| 要问的内容 | 记录 |
|------------|------|
| 能否先提供 20–50 块良品，用来建立良品统计 | |
| 已知不良的现象和大约块数 | |
| 未来两周产线是否连续有产量 | |
| 已知不良能否单独标识，不和未知板混放 | |

## 结论

按现场事实选一个起步方案。同一条线既有回流又有波峰时，拆成两个工位。

| 现场事实 | 建议起步 |
|----------|----------|
| 回流后，品种多，可以把板放到治具上 | S1 离线工位 |
| 回流后，专线节拍稳定，到位能停，有光电 | S2 在线停走 |
| 波峰后，要看连锡、漏焊、锡珠，可以离线把焊接面朝上 | W1 离线目检 |
| 波峰后，主要看透锡和漏插，输送线上方能架相机 | 先做 W1，数据稳定后再加 W2 |
| 波峰后，必须在线看焊接面，设备商能在链条或载具上开窗 | W3 |
| 客户要高速飞拍、线扫或在线翻板 | 不排本次采集 |

开工前逐项确认：

| 条件 | 是 / 否 |
|------|---------|
| 最小特征在选定视野下至少 5 个像素 | |
| 能遮光，环境光不会盖过光源 | |
| 有良品，并尽量有已知不良 | |
| 节拍允许所选方案 | |
| 选 W3 时，载具或链条有取像窗口 | |
| 验收标准已写明 | |
| 表面看不见的位号已改由 X-ray / ICT / 功能测试 | |

有一项关键条件做不到，就改现场或改方案，再约 [两周采集](/guide/poc-playbook#两周采集)。

| 结论项 | 记录 |
|--------|------|
| 选定方案代号 | |
| 是否开工 | |
| 客户待办（遮光、开窗、供板、抽检比例） | |
| 客户确认人 / 日期 | |
