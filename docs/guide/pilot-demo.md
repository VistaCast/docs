# 场景演示

向客户或内部评审展示 VistaCast 时，建议按**真实现场路径**演示，而不是只放静态页。

## 推荐演示脚本（约 20 分钟）

1. **定位一句话**：行业视觉平台，兼容已有枪机，事件优先。
2. **接一路摄像头**：ONVIF / RTSP 或实验室推流，展示在线状态。
3. **规则与告警**：触发客流或区域规则，展示告警列表与 Webhook。
4. **按需预览**：打开 WebRTC 预览，说明无人看时不必长传视频。
5. **场景切换**：按客户行业展示零售 / 仓储 / 产线光学 / 看护之一。
6. **部署选择**：说明门店盒子、直连服务器、定制机三种路径。

## 可强调的产品点

- 同一平台多场景，不是多个互不相通的系统
- 可私有化，数据可留在客户侧
- 与 DataLuminary / SyncroBrain / VistaRemote 的生态闭环
