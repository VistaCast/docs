## 产品在解决什么

VistaCast 把固定摄像头变成可编程的视觉传感器：自动巡检、客流与安防、产线光学检测，以及家庭看护通知——都在同一平台上交付。

| 场景 | 客户得到什么 |
|------|----------------|
| 商业零售 | 客流、时段对比、高峰预警 |
| 仓储物流 | 夜间值守、周界与离线提醒 |
| 产线光学 | 缺件、偏移、焊点与在位检测 |
| 工业安全 | 危险区人员与异常提示 |
| 居家看护 | 跌倒与夜间异常，通知到人（不自动拨打急救电话，不做健康诊断） |

完整规划见 [产品路线图](/guide/roadmap)；怎么接到现场见 [三种部署方式](/guide/deployment-modes)。
