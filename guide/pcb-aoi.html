产线光学检测#

产线光学（AOI）是 VistaCast 上的工厂场景，与门店客流、仓储值守共用同一平台，不是另一个独立产品。

它面向标准整线设备覆盖不到的工位：异形插件、回流焊后的焊点外观、波峰焊后的目检、包装复核。识别在工位主机上完成。管理台配置工位、配方和告警，不在浏览器里加载模型。

适合什么现场#

  • 节拍允许固定机位拍摄的中小制造
  • 异形插件、抽检要求高的汽车电子、柔性板（FPC）
  • 回流焊之后看焊点外观，或波峰焊冷却之后做目检
  • 识别主机用 Apple Silicon，或 Intel / AMD 台式机

现场怎么拍见 SMT 与波峰焊取像，主机参数见 光照与相机选型。

能力规划#

类型 说明
缺件 / 错件 / 偏移 / 立碑 工位区域上的在位与朝向。贴片焊点工位可以顺带检出
SMT 焊点 回流焊后：视觉可见的虚焊征兆、连焊、少焊。区域可以按贴片坐标生成
波峰焊焊点 冷却后：连锡、漏焊、锡珠、拉尖、透锡。机位按产线选择，见 SMT 与波峰焊取像
条码 / 二维码 确定性解码库读出内容，写入序列号。读失败不阻断这张板的检测
批号 / 日期码 离线文字识别读出。质检判定不调用大语言模型。读失败不阻断检测
标签 / 包装 有无、数量、歪斜、封箱，可以和上面的解码、文字识别放在同一工位
胶路 / 组装 断胶、螺钉或接插件在位等相邻工位
良品统计 每个区域记录良品的典型外观和离散程度，偏离过大则标出。不良样本积累之后再训练分类

表面发灰、颗粒感、焊角形态异常，记在「视觉可见的虚焊征兆」里。取像、光照和哪一面看得见，见 SMT 与波峰焊取像。

实测账本#

每个工位单独累计，只统计已经复判的图片：

计数 含义
双方通过 AI 判通过，人工也判通过
双方确认缺陷 AI 判缺陷，人工确认有缺陷
误报 AI 判缺陷，人工判通过
漏检 AI 判通过，抽检中人工发现缺陷

已复判张数记为 N。一致率 =（双方通过 + 双方确认缺陷）÷ N。未复判的通过品不进入分母。漏检只统计抽到的板。

N 小于 30 时显示「样本不足」，不显示百分比。N 够了，百分比保留一位小数。

账本是该客户、该工位、这段时间的事实。市场材料不引用单客户数字。报告怎么用、上线就绪度怎么下结论，见 质检 PoC 手册。

怎么接入#

  1. 用 现场勘察清单 记下板子、节拍、信号和验收标准。
  2. 按取像指南和选型指南固定机位。遮光做不到之前不开始采集。
  3. 按 三种部署方式 部署。
  4. 在管理台绑定摄像头，配置工位、区域和配方。
  5. 告警走与门店相同的规则与出站通道。
  6. 两周采集和转正按 质检 PoC 手册。图像留多久见 证据保留策略。

抽检顺序见 工厂场景评测。

与零售 / 仓储的关系#

同一租户可同时开零售客流与产线光学：共享账号、摄像头资产、告警与权限模型，按站点切换场景配置即可。

能力边界#

  • 本页的产线光学，包括 SMT 焊点、波峰焊焊点和良品统计，是实验室能力：在公开数据集和合成样张上验证功能。这不是客户板 F1，也不是已售设备。「客户板 F1」指在客户产线板上的检出评测成绩，本能力没有这项成绩。
  • 不承诺准确率。能交给客户的，是上一节的实测账本，以及 PoC 的上线就绪度。
  • 方案针对标准整线设备覆盖不到的工位。高速飞拍、线扫、三维激光不在这些方案里。
  • 相机只报告表面可见的缺陷。BGA、QFN 底部焊点、内部空洞和头枕效应交给 X-ray、ICT 或功能测试。对外说法是「视觉可见的虚焊征兆」。
  • 透锡是否合格，以客户规范或 IPC-A-610 对应等级为准。文档不写死填充比例。
  • 组装在位表示有没有、朝向对不对，不是螺丝专项评测成绩。胶路表示表面是否断开，不是内部气孔，也不是金相。
  • 条码解码和文字识别用确定性解码库或离线小模型。质检判定不调用大语言模型。
  • 识别主机是 Apple Silicon 或 Intel / AMD 台式机。Intel Mac（M1 之前的 x86 Mac）始终不是识别主机。
