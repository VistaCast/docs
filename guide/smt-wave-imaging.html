SMT 与波峰焊取像#

这一页是取像的设计起点。板子尺寸、节拍和遮光以 勘察清单 为准，第一次勘察后要改。光照、机位和触发决定画面能不能用。

波峰焊焊点目前按实验室能力采集。能力边界集中在 产线光学检测。相机和主机参数见 光照与相机选型。

示意图表示机位，不是机械图纸。

分辨率#

µm/px = 视野宽度 ÷ 相机像素宽度

视野宽度用微米；若用毫米，先乘 1000 再除。视野宽度是相机实际拍到的实物宽度，用已知尺寸的板或标定板量一次，不是传感器的尺寸。

最小要看的特征至少占 5 个像素。 这是选视野和相机的规则，不是焊点合格阈值。合格与否按客户规范。

例：视野 100 mm、相机 5000 px 时，100 ÷ 5000 = 0.02 mm/px = 20 µm/px。5 个像素对应 0.1 mm。比这更小的间隙，就缩小视野（一块板分成几台固定相机）或提高像素。0.3 mm 的间隙是 15 个像素，满足 5 像素这条规则。0.3 mm 只是演算例子，不是判定门槛。

一台相机盖不住整板时，分区固定拍摄。起步方案不含 XY 运动平台。

光照#

光源 用来看什么 什么时候用
低角环形光 焊点外形、连锡 焊点工位的起步光源
同轴 / 穹顶 压住焊盘和焊锡的反光 低角光下镜面发亮、外形被反光淹没
彩色分层环形光 不同角度配不同颜色，一次曝光，用颜色通道看焊角倾斜 需要焊角倾斜信息时。判定用颜色和外形，不另做一次曝光

三种光可以组合。环境光用遮光罩挡住。在线运动的板用频闪，和曝光同步。参数和识别主机见选型页。

SMT 回流焊后#

这一工位看回流之后的焊点外观：视觉可见的虚焊征兆、连焊、少焊。缺件、偏移、立碑在同一工位顺带检出。表面发灰、颗粒感、焊角形态偏离良品，记在虚焊征兆里。

处理顺序：

  1. 找到 Mark 点，把这张图对齐到黄金样本。
  2. 用贴片坐标（位号、X、Y、旋转、封装）生成每个焊点区域，减少手动画框。
  3. 每个区域看焊料面积、亮度、纹理、相邻焊盘是否被焊料连上，以及彩色分层下的焊角分布。
  4. 和该区域良品的典型外观比较。少焊看面积偏低，连焊看焊盘之间连成一片，虚焊征兆看发灰、纹理发散、外形偏离。
  5. 复判积累之后，再考虑在良品统计之外加分类模型。判定不调用大语言模型。
方案 做法 适合 取舍
S1 离线工位（推荐起步） 回流炉出口收板后，放到固定治具上；扫码枪或脚踏触发；相机俯拍 多品种、小批量 不动产线。节拍设计起点约 5–15 秒 / 板，以勘察为准。位置靠治具
S2 在线停走 炉后接驳台加限位；到位后触发；大板分成多台固定相机 节拍稳定的专线 要和输送协调。分区拍摄，不含 XY 运动

设计起点里的秒数，勘察后按 节拍 改。

S1：收板 → 放上固定治具 → 扫码或脚踏 → 俯拍
S2：到位 → 停住 → 光电触发 → 俯拍

高速飞拍、线扫、三维激光不在这两个方案里。

触发。 扫码枪、脚踏、光电或 PLC 的到位信号走 HTTP 或 MQTT。没有这些信号时，用画面稳定之后拍摄。手上的板还没离开画面时不拍。

追溯。 板条码或载具二维码由确定性解码库读出，写入序列号。工单、批次、班次能扫就扫，不能扫就在工位登记。解码失败不阻断这张板的检测，记录里能看出序列号是解码得到的还是后来补录的。

波峰焊冷却后#

波峰焊和回流焊看的都是焊点外观，机位按这条线的流向来，不照搬 SMT 的俯拍。

插件 → 载具 → 喷助焊剂 → 预热 → 波峰 → 冷却 → 取像

缺陷在哪一面#

缺陷 在哪一面看得见 画面上怎么看
连锡（桥接） 焊接面（板的焊接侧） 相邻焊点之间不该有焊料的地方，焊料连成一片
漏焊 / 无锡 焊接面 焊盘上几乎没有焊料，露出焊盘本色
锡珠 焊接面 禁区里出现小而圆的焊料
拉尖 / 冰柱 焊接面 轮廓向外拖出一条。外形判读，先积累样本，精度有限
透锡不足 / 少锡 元件面（板的元件侧） 通孔焊盘环上，焊料有没有爬上来
元件浮高 / 歪斜 / 漏插 元件面 在位和朝向

透锡是否合格，以客户规范或 IPC-A-610 对应等级为准，配方里做成阈值。本文不写填充百分比。

三种机位#

方案 做法 适合 取舍
W1 离线目检（推荐起步） 冷却后取出，焊接面朝上放进治具；扫码或脚踏；俯拍 大多数小厂，要看焊接面 产线本身不用改。节拍设计起点约 5–10 秒 / 板，以勘察为准
W2 元件面在线俯拍 出口输送线上方架相机，到位触发，频闪 主要关心透锡和漏插 相机在上方，不碰载具。只能看元件面，连锡和拉尖不在这一面
W3 焊接面在线仰拍 两段链条之间或载具开窗，相机在下方朝上，频闪 设备商能配合改机械的专线 要开窗。助焊剂和热会污染镜头，相机要有防护。载具挡住焊接面时必须开窗

建议顺序：先用 W1 把焊接面的数据跑起来，产线稳定后再加 W2 做在线透锡和漏插。W3 只在客户愿意改机械、并且设备商能开窗时做。在线翻板不在方案里。

触发。 与 SMT 相同：光电或载具到位走 HTTP / MQTT，扫码枪同样可以触发；没有信号就用稳定画面。只读取到位信号，不改链速，不写 PLC。

追溯。 板条码或载具二维码解码后写入序列号，规则与 SMT 相同。

表面可见的边界#

相机报告的是板面上看得见的焊接外观。

画面里可以讨论的 要交给别的手段
润湿不良在表面上的征兆：发灰、颗粒、焊角形态异常 BGA、QFN 底部焊点
连锡、漏焊、锡珠、拉尖（拉尖先作实验室采集） 内部空洞
元件面上看见的透锡 头枕效应：焊球和焊盘看起来贴在一起，实际没有润湿，板面相机分辨不了

对外说法用「视觉可见的虚焊征兆」。X-ray、ICT 和功能测试负责表中右列。勘察时把这些位号标出来，不放进相机的验收项。
