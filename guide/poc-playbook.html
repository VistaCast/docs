质检 PoC 手册#

质检 PoC 把一个工位跑起来：勘察、两周采集、人工复判，然后用这家客户自己的板交出实测账本和上线就绪度。

账本是这段数据上的事实。PoC 合同不承诺准确率。焊点外观目前按实验室能力采集，边界集中写在 产线光学检测。

线索 → 勘察 → 两周采集 → 评测汇报 → 转正

流程一览#

阶段 产出 客户配合
线索 线索单：工厂、工位类型（回流后 / 波峰后 / 包装）、现有检测缺口、对接人、能否供板 指出一条线和一种板，说明现在谁在目检
勘察 勘察单、建议取像方案、开工条件是否满足 量板、看节拍和信号、给出验收标准、允许看工位和现有设备
两周采集 图像、判定、复判记录、初步账本 按平时节拍供板；安排复判；两周内固定光照和机位；标识已知不良
评测汇报 评测报告：账本、上线就绪度、改进项、复判工时 品质负责人参会，确认标准没有换过，指出不能接受的漏检类型
转正 工位服务约定、复判编制、证据保留天数 指定管理员和班次，确认数据留在现场

转正文件另定服务方式。相机、镜头和光源按选型参数现场配置。

线索#

确认这张单子属于「标准整线设备覆盖差、缺陷在板面上看得见」的工位：异形插件、回流焊后的焊点外观、波峰焊后的目检、包装复核。

线索单写清：

  • 工厂、产线、班次
  • 工位是回流后、波峰后，还是包装
  • 现在靠人工目检，还是已有设备盖不住这一站
  • 品质或工艺对接人
  • 能否在两周里供板，并拿出良品和已知不良

缺陷主要在芯片底部，或者客户要的是高速飞拍整线时，把原因写在线索单上，不安排勘察。底部焊点和内部空洞的分工见 取像指南。

勘察#

带 现场勘察清单 去现场。清单上的尺寸和节拍，用来改 取像方案 里的设计起点。

产出三样东西：填完的勘察单、建议的方案代号（S1 / S2 / W1 / W2 / W3）、开工条件是否满足。

开工前要同时满足：最小特征在选定视野里至少占 5 个像素、环境光能被遮住、有良品可采集、节拍容得下所选方案、验收标准已经写明。缺任何一项，先改现场或改方案，再约采集周。光照这一关过不了，不开始采集。

客户侧要有人能打开现有光电、条码枪或脚踏的接法，并给出内控或 IPC-A-610 等级。透锡填充比例引用那份文件，勘察单不另写一个通用百分比。

两周采集#

采集窗口是连续两周。产线中断的日期在报告里标出来，不把没有产量的日子写成已验证。

这阶段固定机位、光照和配方，采集图像，由客户人员复判。我方可以在现场带教复判台操作。用 20–50 块良品建立每个区域的良品统计起点；已知不良单独标识，用来核对征兆是否出现在画面里。

两周里可以调光照、区域和阈值。每次调参前后把账本分段，调试日不并进稳定段。报告以光照和配方稳定之后的那段为主，并写明稳定前有多少天。

判定在工位主机上完成，图像和记录先留在现场，再同步到管理台。质检判定不调用大语言模型。条码或文字识别失败时，这张板的检测继续，记录里能看到序列号是解码得到的还是后来补录的。

本阶段的产出是图像、判定、复判记录和初步账本。合同里不追加检出率条款。

客户要做的事：按平时节拍供板；指定复判的人并保证每天有时间；两周内不挪相机、不改遮光和治具；板上的码保持可扫。

评测汇报#

听众是品质负责人。报告用客户自己的数据，市场材料不引用这份数字。

报告包含：

  • 窗口起止，以及实际有产量的天数
  • 实测账本（口径见 产线光学检测）：双方通过、双方确认缺陷、误报、漏检、已复判张数 N
  • N 小于 30 时写「样本不足」，不显示百分比；N 够了，一致率保留一位小数
  • 这段窗口的直通率和缺陷分布，旁边写上检测张数
  • 哪些征兆在画面里看得到；哪些位号交给 X-ray、ICT 或功能测试
  • 光照、区域、阈值还要改什么
  • 复判人力估算
  • 上线就绪度

上线就绪度综合三件事：已复判样本量、一致情况、近 7 个有产量日的趋势是否平稳。不折成一个对外百分比，也不设统一的百分比门槛。结论用下面三句之一：

结论 什么时候用
样本还不够 已复判不足 30 张，或有产量的天数太少，趋势看不出来
先改光照、机位或阈值，再采集 画面仍受环境光、反光、拖影或位置晃动影响，稳定段还没有形成
可以讨论转正 样本量够、机位和光照在稳定段里保持不变、账本已分段、复判工时已算出

「可以讨论转正」表示资料够开会，不等于检出承诺。转正不自动发生。

转正#

转正约定四件事：工位服务方式（在转正文件里另定）、复判编制、证据保留天数、数据留在客户现场。

保留天数的默认值见 证据保留策略，工位上可以改。

客户指定管理员和复判班次，确认磁盘放在厂内。结论是「样本还不够」或「先改现场」时，可以续采，也可以停止。停止之后图像和记录仍在客户侧。

新的板型、新的工位重新勘察、重新做配方。上一块板的阈值不自动套到下一块板。

复判人力#

用这家工厂采集周的计时，不用别的工厂的秒数。

  1. 对连续复判计时。目标至少 30 块；两周总共不足 30 块就全部计入，并写明块数。不良候选和通过品分开计。
  2. 单块秒数取中位数，避免一次查找标准的长停拉高结果。
  3. 不良品全部复判。通过品按勘察单里的抽检比例；通过品也全检时，比例取 1。
  4. 代入采集周的日产量和不良比例：
日复判工时（小时）
  = 日产量 ×（不良比例 × 不良单块秒数
              +（1 − 不良比例）× 抽检比例 × 通过单块秒数）
    ÷ 3600
  1. 一名复判员每天能用于复判的小时，按班次扣除上下料和停线处理之后填写，不预设成固定班时。
  2. 人数 = 日复判工时 ÷ 每人可用小时，向上取整。
  3. 人数超出客户能安排的编制时，先用复判台上的批量操作和快捷键压缩通过品的单块秒数，再重算。不良品保持全检。
  4. 秒数、产量、工时和人数写进评测报告，作为转正时的编制依据。

高风险位号可以在转正约定里保留人工终检。终检发现的漏检仍计入账本。

合同要点#

写进 PoC 约定时保留这些条。这不是报价单。

  1. 目的。 完成勘察、两周采集和评测汇报。交付勘察单、取像与光照记录、实测账本、评测报告、上线就绪度和复判人力估算。
  2. 不承诺准确率。 不把公开数据集或合成样张上的实验分数写进验收。焊点外观按实验室能力采集，本约定不把它写成已售设备。
  3. 验收材料。 用客户自己的板，和客户自己的规范。规范采用 IPC-A-610 时，写明等级。透锡填充比例引用该文件，不在合同里写死一个通用百分比。
  4. 范围。 约定的工位和板型，以及勘察单上的方案代号（S1 / S2 / W1 / W2 / W3）。相机报告表面可见的缺陷，对外说法用「视觉可见的虚焊征兆」。
  5. 范围外。 高速飞拍、线扫、三维激光、在线翻板、改写 PLC 或链速、X-ray、ICT、功能测试。
  6. 数据。 图像和记录默认留在客户现场，不默认传到公网。保留天数按 证据保留策略，可在工位上修改。
  7. 客户义务。 提供工位、电源和网络、遮光条件、稳定供板、已知不良（如果有）、验收标准、复判人员，以及现有光电或扫码枪的对接人。
  8. 复判。 PoC 期间由客户人员复判，我方带教操作。转正前用上一节的实测秒数约定编制。
  9. 结束。 两周结束交付报告。客户可以转正，也可以停止。停止后数据仍在客户侧。
  10. 硬件。 相机、镜头、光源、治具和工控机按 光照与相机选型 现场配置。合同不绑定品牌。
