混合推理与云桥（诚实口径）#

VistaCast 一个平台、三条推理平面。控制面在 server；server / Admin web 永不加载模型权重。禁止自建 VistaCast GPU。允许 ai 按量编排第三方云视觉。不是 Cloud Bridge 已售，不是 NPU。

三条平面#

平面 何时 现在跑在哪
1 前台伴随 店长巡检 / 家属打开 App Electron / RN 窗口 WASM（窗口 YOLO/Chat）。不是 Hexagon / APU
2 常驻边缘 仓储、连锁；盒子通电时的自运维检测 Compose 里的 ai Runtime 拉 RTSP
3 付费云桥 无盒子或不支持边缘时的候选帧 / 低频快照 ai 调第三方 HTTP；控制面按次预占，超限 429。空 CLOUD_BRIDGE_SKU_ID = 无 SKU。不是已售

固定枪机 不能 用前台窗口代替边缘盒。低于 Android 认证下限 时回退平面 2 或 3。

前期不承诺平台 24/7（FR-PLT-17）：平面 2 门店盒子是客户自运维（通电才跑）。对外承诺 24/7 仅已售定制模组或付费云监控（平面 3 / 托管进流）。当前均未售。App 断连后 不会 由 server 接管拉流。

没有 App、没有盒子，怎么取帧？#

没有帧就没有检测。禁止「装都不装，摄像头自动上云端大模型」。

方式 状态
门店盒子 / 本机 ai 拉 RTSP ✅ 现有路径
OEM 固件推关键帧 ⬜ 未做
NVR / 第三方 JPEG webhook ⬜ 未做

Cloud Bridge（FR-AI-10 / FR-OPS-02）#

  • 只送候选 JPEG 或低频快照，不是连续全流默认上云
  • 边缘 online / degraded 时控制面停云：租约 reason=edge_healthy，预占返回 409
